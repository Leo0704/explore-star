# 钩子模板：评论回复

## 风格说明

我们的钩子风格统一是「朋友推荐，不像销售」——像朋友在评论区分享经验，不是一上来就留联系方式。

## 结构

好的评论回复 = 认同 + 经验 + 钩子

1. 认同：先认同对方说的情况
2. 经验：分享一个具体的经验或数字
3. 钩子：引导对方进一步交流

## 模板库

### 模板 1：认同 + 具体数字 + 引导

```
看到你也遇到 XXX 问题，我们之前帮一个客户（杭州的，也是做 XXX 的），
用了一套方法，2 个月省了 30 万库存。
如果你也在被这个问题困扰，我可以分享一下我们的思路，不收费。
```

适用：电商/供应链/库存相关问题

### 模板 2：认同 + 案例 + 引导

```
你说的这个情况很普遍。我上周刚帮一个深圳的客户解决了类似的问题，
他原来是 5 个人专门处理客服，现在 2 个人就够了。
你可以把你的情况说说，我帮你分析一下，不一定适合你，但多个思路总没坏处。
```

适用：客服效率/团队管理相关问题

### 模板 3：认同 + 预警 + 引导

```
你这个方向是对的，但有个坑要注意——很多人在第一步就踩了，
因为没有先做业务盘点，后面的工具选型全白费。
如果你现在还在前期调研阶段，我可以发你一份《业务诊断清单》，照着做不会踩坑。
```

适用：AI 选型/数字化转型相关问题

### 模板 4：轻松 + 具体 + 留钩子

```
哈哈，你这个痛点我们太熟了。之前有个客户跟你情况差不多，
后来用了一个「三步诊断法」，2 周就把问题理清楚了。
你要是感兴趣，我可以把方法发你，自己先测测看，不一定适合你哈。
```

适用：泛用型，通用场景

## 禁止使用的表达

- ❌ 「我们有专业团队」（太销售）
- ❌ 「欢迎联系我们」（太生硬）
- ❌ 「我们的产品可以帮你」（太硬广）
- ❌ 留微信号/手机号（在抖音评论里违规）

## 注意事项

1. 钩子不要太长，控制在 30 字以内（核心部分）
2. 具体数字 > 模糊概念（「30 万」> 「省了很多」）
3. 不要在第一条评论里直接留联系方式，先建立信任
4. 如果对方回复了，再自然地引导加微信
