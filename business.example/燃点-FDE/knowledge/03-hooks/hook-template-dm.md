# 钩子模板：私信

## 风格说明

私信比评论更私密，但也更容易被当成「骚扰」。我们的原则是：
- 像朋友发消息，不像销售发传单
- 提供价值，不强行推销
- 给对方选择权，不死缠烂打

## 结构

好的私信 = 身份 + 来由 + 价值 + 钩子

1. 身份：我是谁（用昵称，不用头衔）
2. 来由：怎么找到你的（评论了你的视频 / 看了你的某个内容）
3. 价值：能给你什么（一个具体的东西/思路/方法）
4. 钩子：让对方愿意继续聊（但不强求）

## 模板库

### 模板 1：评论回复后跟进

```
老王，看到你评论区问的「AI 选型」问题，我之前整理了一份《AI 选型 checklist》，
专门帮中小企业避坑的。你要是还没解决这个问题，我可以发你看看，不一定能用上，
就当多个参考。

不打扰～ 老张
```

适用：评论互动后的跟进

### 模板 2：加微后自我介绍

```
老王好，我是老张，之前在评论区跟你聊过 AI 落地的事。

加你微信是想把那两份资料发你：
1. 《业务诊断清单》（帮你在选工具之前先搞清楚需求）
2. 《AI 选型 checklist》（我们验证过的 12 个常见坑）

先看看，不适合可以直接扔掉，不收费也不推销。

有问题随时找我～ 老张
```

适用：加微信后的第一条私信

### 模板 3：沉默客户再激活

```
老王，最近怎么样？

上次给你发的《AI 选型 checklist》看了吗？最近有个客户照着做，
2 周内就把选型搞定了，省了不少冤枉钱。

如果你已经有思路了，就当我打扰了；如果还在纠结，可以说说情况，我帮你看看。

祝好～ 老张
```

适用：30 天沉默客户的再激活

### 模板 4：提供价值的钩子

```
老王，我上周发了一篇《为什么你的 AI 工具总用不起来》的文章，
里面提到了一个「需求-工具」匹配模型，你看了吗？

感觉你之前的痛点正好是这个。有空可以聊聊，不一定帮你解决问题，
但多个视角总没坏处。

—— 老张
```

适用：已有关注/互动的客户

## 禁止使用的表达

- ❌ 「您好，我是 XXX 公司的销售」（太正式）
- ❌ 「我们的产品优势是...」（太硬）
- ❌ 「请问您什么时候方便通话？」（太强迫）
- ❌ 「如果您不感兴趣可以忽略」（虽然是给选择，但暗示对方可能不感兴趣）

## 注意事项

1. 私信在早上 8-9 点或晚上 8-9 点发效果最好
2. 不要发超过 3 条私信（除非对方回复了）
3. 如果对方没有回复，30 天后再试一次，再不回复就放弃
4. 永远不要在私信里直接报价（要引导到预约诊断）
