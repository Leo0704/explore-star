# 合规说明

## 使用场景

探星是一个**抖音评论截流工具**，设计用于：
- 发现有真实需求的潜在客户
- 提供有价值的信息和帮助
- 遵守平台规则和用户隐私

## 禁止的使用场景

❌ **禁止**：
- 批量发送垃圾私信
- 发布虚假或误导性内容
- 冒充他人或伪造身份
- 收集和出售用户数据
- 绕过平台安全机制
- 用于骚扰或诈骗

## 最佳实践

### 1. 尊重用户隐私

- 只收集评论中公开的信息
- 不收集敏感个人信息
- 用户明确拒绝后立即停止联系

### 2. 提供真实价值

- 钩子话术要真实、有用
- 不夸大产品效果
- 承诺要兑现

### 3. 遵守平台规则

- 遵守抖音的服务条款
- 不使用自动化工具绕过人机验证
- 限制每日操作数量（详见 `config/safety.json`）

### 4. 安全监控

- 定期运行 `npx explore-star doctor` 检查系统状态
- 关注风控信号（详见 `scripts/safety-monitor.ts`）
- 紧急情况使用 `config/EMERGENCY_STOP` 立即停止

## 数据合规

- 所有数据存储在本地
- 不上传到任何外部服务
- 用户数据删除请求应被尊重（手动删除 `data/` 目录）

## 免责声明

探星是一个**自动化工具**，使用者对以下行为负责：
-遵守当地法律法规
- 遵守抖音平台规则
- 不进行任何违规操作

作者不对以下情况负责：
- 使用者违反平台规则导致的账号封禁
- 使用者进行违规操作导致的法律问题
- 数据泄露（请保护好本地数据）
